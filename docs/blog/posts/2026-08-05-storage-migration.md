# Storage Migration

On Thursday, August 6th, 2026 from 8:00AM to 5:00PM, the SSCS cluster will under a major upgrade to storage.

<!-- more -->

This upgrade to our research storage system will increase capacity and performance.

**Wednesday Afternoon:**

If you have files that need to be available Thursday morning, you can copy a small number to your local worksation.  After the migration is complete, you can upload them back to the cluster.

At 5pm Wednesday, SSCS server admins will bring down cluster systems: Scheduled jobs will be allowed to run until the morning on:

- Acropolis
- Athens
- Cronus

During the migration, users will see connections to the storage break.

If you experience any issues with reconnecing, accessing home or lab shares once systems are online, please reach out immediately to ssc-server-support@lists.uchicago.edu for support.
