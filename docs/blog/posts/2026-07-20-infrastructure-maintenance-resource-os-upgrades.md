# Infrastructure Maintenance: Resource & OS Upgrades

From July 27th to July 30th, the SSCS cluster will undergo an upgrade to infrastructure resources and the Red Hat Enterprise Linux (RHEL) operating system.

<!-- more -->


This work affects core cluster services and requires an extended maintenance window of approximately 4 days (July 27-30).

During this time, access to the cluster and core services such as Slurm will be unavailable. 

In preparation, please take the following steps before the maintenance window begins:

- Ensure all running jobs and workflows are completed prior to the window

- Checkpoint long-running jobs where possible to prevent loss of progress

- Avoid submitting new jobs that could extend into the maintenance window

We will send a follow-up notification via our listserv once maintenance is complete and all services have been restored.

If you have any questions or need assistance planning around the maintenance window, please contact us at ssc-server-support@lists.uchicago.edu.
